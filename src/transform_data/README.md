# Steps to extract data

(Must follow the specified order)

1. Extract `dim_meals`:
   3.1. File `1_extract_to_inter.ipynb`
   3.2. File `2_extract_meals.ipynb`
2. Extract `dim_restaurants`: File `extract_dim_restaurants.ipynb`
3. Extract `dim_meal_types`: File `extract_dim_meal_types.ipynb`
4. Extract `pos`: File `extract_pos.ipynb`
5. Extract `pos_daily_snapshot`: File `extract_pos_daily_snapshot.ipynb`
6. Extract `waste`: File `extract_waste.ipynb`

Other files in the following list are optional:

- `extract_dim_exams_uhelsinki.ipynb`
- `extract_dim_holidays_uhelsinki.ipynb`
- `extract_dim_meal_names_embd.ipynb`
